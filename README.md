# html_css_js — Web制作の練習

Udemy「HTML/CSS + JavaScriptをちゃんと学ぶ講座」(たにぐち まこと) に沿った学習と、
コーディング案件の受注に向けた自主練習の置き場所。

## フォルダの使い分け

| フォルダ | 何を置くか |
|---|---|
| `lesson/` | 講座を見ながら書いたコード。写経。 |
| `practice/` | **提出物。** 模写・カンプ再現。1課題1フォルダ（`001_cafe-site/` など） |

**進捗として数えるのは `practice/` だけ。** `lesson/` は見ながら書いたものなので、
「できるようになった」証拠にはならない。動画を閉じて何も見ずに書けたものを `practice/` に置く。

## このフォルダは自動補完を切ってある

`.vscode/settings.json` で補完・Emmet・自動閉じタグ・自動整形を全部オフにしている。
書けるようになるまでの期間限定の設定。

**VS Code ではこの `html_css_js` フォルダを直接開くこと**（File → Open Folder）。
親フォルダを開くと、この設定は読み込まれない。

案件を受け始めたら設定は戻す。実務では補完を使うのが普通で、速度が価値になるため。
